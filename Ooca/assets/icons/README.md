# About icons

`ant-design-outlined.svg` contains 20 original Outlined icons from
`@ant-design/icons-svg` version 4.6.0, distributed under the MIT license in
`ant-design-LICENSE.txt`.

- Source: https://github.com/ant-design/ant-design-icons
- Icon reference: https://ant.design/components/icon/
- Change icon assignments in `data/about-icons.json`.
- The tool icons represent their use; they are not product brand logos.
- `scripts/about_page.py` renders the icons. Run `scripts/build.py` after changing
  assignments to regenerate About, then `npm run build` for English and Thai output.
- Icons are decorative, inherit the page colors, and use one local SVG sprite.
