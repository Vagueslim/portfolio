# Portfolio work and evidence

A bilingual design portfolio. Project identity and case evidence are shared across Home, the project list and case studies; their presentation can differ.

## Language

**Project**: One body of professional work with a stable identity, title and primary cover.
_Avoid_: treating each page placement as a different project.

**Case Study**: The detailed account of a project's role, decisions, limitations and evidence. It does not imply sole ownership or measured production impact.

**Project Cover**: The primary promotional image for a project. The project list uses it; other placements inherit it unless explicitly overridden.
_Avoid_: using “cover” for every screenshot in the story.

**Case Overview**: The visual introduction to a case. It may be an image, paired images, a collage or an explanatory flow.

**Evidence Image**: A screenshot, diagram or original presentation supporting a specific passage. Its identity and caption are independent of the project cover.

**Home Feature**: A selected placement of a project on Home, with its own order, wording and optional visual choice.
_Avoid_: assuming the order on Home must match the project list.

**Language**: English or Thai copy selected by the page URL. Text embedded in source screenshots remains part of the original evidence.
